# The Boob Doctor website

Static site for theboobdoctor.org (plain HTML and CSS, no build step).

## Files
- `index.html`: homepage (About, Podcasts, Book, Services)
- `shop.html`: Webinars and courses
- `styles.css`: all styling
- `images/`: logo, wordmark, headshot, icons
- `CNAME`: tells GitHub Pages the custom domain
